## Overview

This portfolio presents Muhammad Ayan's work across Python development, backend engineering, AI-driven workflow automation, and the path toward AI security. It is designed to give recruiters, collaborators, and clients a clear view of his skills, projects, experience, certificates, and resume.

## Highlights

- Responsive, polished single-page portfolio built for desktop and mobile
- Animated hero section with rotating professional roles
- Interactive theme and motion controls
- About, skills, projects, experience, education, certificates, and resume sections
- Project filters, project identity icons, source-code links, and expandable case studies
- Embedded resume preview with a direct PDF download
- Smooth reveals, staggered card motion, and subtle 3D depth effects

## Run Locally

### Prerequisites

- Node.js 16 or later
- npm

### Installation

```bash
git clone https://github.com/muhammadayantoorie-creator/muhammad-ayan-portfolio.git
cd muhammad-ayan-portfolio
npm install
npm start
```

The development server starts at [http://localhost:3000](http://localhost:3000).

## Available Scripts

| Command | Purpose |
| --- | --- |
| `npm start` | Runs the app in development mode. |
| `npm test` | Runs the test suite. |
| `npm run build` | Creates an optimised production build in `build/`. |

## Deployment

This project is deployed with Vercel. New commits pushed to the `main` branch can be redeployed from the Vercel project dashboard.

For a new Vercel deployment:

1. Import this GitHub repository into Vercel.
2. Select **Create React App** when prompted.
3. Use `npm run build` as the build command and `build` as the output directory.
4. Deploy.
